# Userow

**Userow** is a full-stack web application designed for user registration, authentication, and management, providing an intuitive interface and a REST API for account administration and access control.

The project aims to explore web development best practices, including software architecture, frontend and backend integration, authentication, authorization, and data persistence.

## Technologies

### Frontend

- Vite
- React
- Tailwind CSS

### Backend

- Node.js
- Express
- Dotenv
- JSON Web Token (JWT)
- Bcrypt

### Database

- PostgreSQL

## Funcionalidades previstas

- New user registration.
- JWT-based user authentication.
- Profile information retrieval and updates.
- User account deletion.
- Role-based access control (RBAC).
- Admin dashboard for user management.
- Route and resource protection through authentication and authorization.

## Development Status

Early development.

Features and architecture may change as the project evolves.
